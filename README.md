## ✨ About

**Lekas** is an offline-first Android app for university students to capture tasks and deadlines, organized per course, with reliable local reminders. No account, no cloud, no collaboration — all data stays on your phone.

> _"Capture tasks from chat in 5 seconds, auto-organized per course, and reminded on time."_

## 🎯 Features (Phase A & B)

- 📚 **Spaces (courses)** with color, alias for quick-add parser, notes (lecturer, room, link)
- ✅ **Tasks** with type, deadline, priority, status, weight, estimate, individual/group
- 📅 **Today screen** sorted by urgency score, with overdue/today/this-week sections
- 🔔 **Local reminders** (H-3, H-1, 3h, 30min) with boot receiver and battery-aware setup
- ⚡ **Quick Add** with Indonesian/English natural-language parser
- 📲 **Share from WhatsApp** (text + screenshot OCR)
- 📆 **Monthly calendar** with per-course colored dots
- 💾 **Local backup & restore** (JSON export/import)
- 🌙 **Dark mode**, two languages (Indonesian default, English)
